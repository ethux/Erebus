# Contributing

1. Fork, branch from `main`, keep PRs to one change.
2. `make dev` then `make check` before pushing.
3. On your first PR a bot asks you to sign the [CLA](CLA.md) by commenting on the PR.
   The CLA lets ETHUX offer Erebus under commercial terms alongside the AGPL.

Code in `pro/` is under the Elastic License 2.0; contributions there follow the same CLA.
